# فحص سيرفر FastEgy AI

السكريبت ده بيعمل فحص كامل لمساعد الذكاء الاصطناعي اللي على السيرفر، وبيطلّع تقرير واحد نبني عليه خطة قاعدة المعرفة.

السكريبت:

`fastegy_ai_audit.sh`

---

## إيه اللي بيفحصه

1. موارد السيرفر: المعالج والذاكرة والمساحة.
2. كل الحاويات اللي شغالة على السيرفر.
3. ملف الإعدادات الرئيسي:

   `librechat.yaml`

4. ملف المتغيرات (أسماء بس، والمفاتيح السرية بتتخفي):

   `.env`

5. خدمة البحث في الملفات وقاعدة المتجهات:

   `rag_api` + `pgvector`

6. الوكلاء الموجودين، وتعليماتهم، وعدد الملفات المرفوعة لكل وكيل.
7. الاستخدام في آخر 30 يوم: عدد المحادثات والمستخدمين، وأكتر النماذج استخدامًا، والتقييمات.
8. آخر الأخطاء في السجلات.

---

## الأمان

- السكريبت للقراءة بس: مش بيعيد تشغيل حاجة ولا بيعدّل أي إعداد.
- كل سطر في التقرير بيعدّي على فلتر بيخفي مفاتيح الخدمات وكلمات السر.
- مش بيقرا نصوص محادثات الموظفين، بيعدّ الأرقام بس.
- يُفضّل تراجع التقرير بعينك قبل ما تبعته.

---

## طريقة التشغيل

ادخل على السيرفر من الطرفية في لوحة

Hostinger

أو بأمر

`ssh root@<IP>`

وبعدين نفّذ:

```bash
curl -fsSL https://raw.githubusercontent.com/mohamedfastegy/odoo/claude/magical-allen-wx2wnm/fastegy_ai/fastegy_ai_audit.sh -o fastegy_ai_audit.sh
sudo bash fastegy_ai_audit.sh
```

لو أمر التحميل رجّع خطأ (المستودع خاص)، افتح الملف على

GitHub

واضغط

Raw

وانسخ المحتوى كله، وبعدين:

```bash
nano fastegy_ai_audit.sh      # الصق المحتوى واحفظ بـ Ctrl+O ثم Ctrl+X
sudo bash fastegy_ai_audit.sh
```

التقرير بيتحفظ في:

`~/fastegy_ai_audit_<التاريخ>.txt`

ابعته في المحادثة، أو اعرض محتواه بأمر:

`cat ~/fastegy_ai_audit_*.txt`
