# إضافة فاست إيجي لتخزين مرفقات أودو على جوجل درايف

نسخة تجريبية لأودو ١٨. تحفظ المحتوى في مجلد خاص على درايف وتعرضه من أودو، مع بقاء بيانات الربط الصغيرة داخل قاعدة أودو. تحتاج استضافة تسمح بإضافات بايثون المخصصة. لا تُعمم على كل الموديلات عند التثبيت.

## المكونات

الإضافة الأساسية:

```
fastegy_drive_storage
```

امتداد اختياري لتطبيق المستندات في أودو إنتربرايز:

```
fastegy_drive_documents
```

اعتمادا المجتمع المفتوح مرفقان دون تعديل، مع التراخيص وإثبات النسخة في ملف قفل الاعتمادات:

```
dependencies/fs_storage
dependencies/fs_attachment
DEPENDENCIES.lock.json
THIRD_PARTY_NOTICES.md
LICENSES/
```

## الوظائف

- صحة الاتصال وحصة حساب جوجل وسجل العمليات ونشاط متابعة داخلي.
- مهام نقل مستقلة محفوظة في قاعدة البيانات، وإعادة محاولة مؤجلة، والتحقق من البصمة.
- ترتيب اختياري لمجلدات الشركة والموديل والسجل والحقل، مع اسم ونوع ملف حقيقيين وهوية تخزين ثابتة.
- رفع مقسم قابل للاستكمال أثناء العملية، وتنزيل متدفق مع نطاقات بايت. إعادة تشغيل العامل لا تستعيد موضع الجزء الجاري؛ مهام النقل تعيد استخدام هوية ثابتة للرفع المكتمل.
- قواعد حسب الموديل والحقل والشركة ونوع الملف وحجمه ونطاق السجلات، مع معاينة قبل التفعيل.
- فهرس الملفات، وربط ملف موجود باختصار خاص دون تكرار محتواه، أو إنشاء نسخة مستقلة. يتاح منتقي جوجل بعد ضبط مفتاحه ورقم المشروع.
- فهرس استعادة قابل للتصدير، وإصدارات سابقة، وفحص المفقود واليتيم على دفعات، وفترة احتفاظ، وسلة قابلة للاستعادة. لا حذف نهائي تلقائي.
- تشفير أسرار الاتصال بمفتاح خارجي قابل للتدوير، وحماية نسخ قواعد البيانات من الكتابة على مخزن الأصل.
- إعداد صريح للمساحات المشتركة.
- ربط اختياري بمجلدات تطبيق المستندات، ومشاركة خاصة لمستخدم محدد بمدة وإلغاء.
- جرد تعريفات حقول الملفات المثبتة وتصنيف المرفقات والأعمدة المباشرة والحقول المحسوبة.

## إعداد أول تجربة

١. ثبت متطلبات بايثون في بيئة أودو، وأضف مسارات الإضافات الأساسية واعتمادات المجتمع إلى إعداد الإضافات. حافظ على ملف متطلبات الاستضافة القائم عند إضافة المكتبات المطلوبة.

```
requirements-odoo.txt
```

٢. ثبت الإضافة الأساسية، وأنشئ مشروع جوجل وفعل واجهة درايف، واضبط عميل تفويض من نوع تطبيق ويب. انسخ عنوان العودة الذي تعرضه شاشة الإضافة كما هو.

٣. اتصل بحساب جوجل بالصلاحية المحدودة الخاصة بالملفات، ثم اختبر المجلد الخاص قبل السماح بالكتابة. راجع [اختيار صلاحيات درايف](https://developers.google.com/workspace/drive/api/guides/api-specific-auth).

٤. ابدأ بموديل وسجل تجريبي واحد وصورة وملف. تحقق من العرض والصلاحيات والبصمة وغياب المحتوى الدائم من قاعدة أودو. تبقى المهام المجدولة الجديدة معطلة حتى تفعيلها صراحة بعد التجربة.

٥. شغل جرد التغطية قبل توسيع النطاق. الحقول المحفوظة مباشرة في أعمدة قاعدة البيانات والبيانات المضمنة في النصوص ومسارات الرفع المخصصة تحتاج مراجعة منفصلة.

## الأسرار وحدود التشغيل

مصدر مفتاح التشفير المفضل متغير بيئة يوفره مشغل الاستضافة:

```
FASTEGY_DRIVE_SECRET_KEYS
```

يتاح بديل من ملف مملوك لمستخدم خدمة أودو وصلاحيته قراءة وكتابة للمالك فقط:

```
~/data/.fastegy-drive/keys.json
0600
```

يلزم حفظ نسخة مستقلة آمنة من المفتاح وتجربة استعادته وبقائه بعد إعادة بناء الاستضافة. فقد المفتاح يمنع فك الأسرار. لا يحل النسخ الاحتياطي لقاعدة أودو وحده محل نسخة مستقلة لمحتوى درايف.

بعض مسارات الصور الأصلية في أودو تحتاج المحتوى كاملاً في الذاكرة. الحد الافتراضي عشرون ميبيبايت؛ الزيادات تحتاج قياس الذاكرة والضغط. لا تتحول المساحة المحلية إلى صفر لأن بيانات الربط تبقى في أودو.

الاختصار يتوقف عند تغيير الأصل أو حذفه أو سحب الصلاحية. مستندات جوجل الأصلية تحتاج تصديرًا قبل هذا المسار. وضع تفويض جوجل الخارجي التجريبي يحتاج معالجة قبل الإنتاج، وقد تنتهي صلاحية تجديد التفويض بعد سبعة أيام. راجع [إرشادات التفويض](https://developers.google.com/identity/protocols/oauth2/resources/best-practices).

## التحقق

اختبارات الموصل والسياسات المحلية:

```bash
python -m pip install -r requirements-test.txt
python -m pytest -q tests
```

آخر نتيجة: ٥٦ اختبارًا محليًا ناجحًا، و٣٣ حالة تكامل ناجحة داخل أودو على بيئة الاختبار. تحاكي حالات التكامل النقل الخارجي، وتفحص مسارات التفويض الحقيقية عبر خادم داخلي. جرى تجاوز التجهيز المسبق لملفات الواجهة في عملية الاختبار وحدها؛ لا يعد ذلك اختبارًا للواجهة أو الضغط. حالتا امتداد المستندات لم تُشغلا لأن التطبيق غير مثبت. المساحات المشتركة والمنتقي وبقاء مفتاح التشفير بعد إعادة البناء تحتاج اعتمادًا فعليًا منفصلاً.

نجحت أيضًا تجربة فعلية مستقلة لصورة وملف نصي: الاسم والنوع صحيحان داخل درايف، والبايتات متطابقة عند القراءة، ومحتوى الملف غير محفوظ في قاعدة أودو. هذا يثبت المسار التجريبي المحدد، ولا يثبت التغطية الشاملة أو أداء الملفات الكبيرة.

وسم اختبارات أودو:

```
fastegy_drive_trial
```

هذا المستودع يحتوي كود الإضافة والاعتمادات والاختبارات؛ ملفات مفاتيح الحسابات وإعدادات السيرفر وبيانات العملاء ليست جزءًا منه.
